R packages

- R package `multEIVunmix`. [[GitHub]](https://github.com/vksingh28/multEIVunmix)
  Implementation of additive and multiplicative errors-in-variables models for hyperspectral unmixing, accompanying research by Singh & Hoff. The package fits Bayesian MCMC samplers to individual hyperspectral pixels using a library of pure reference spectra, and includes a full replication pipeline (data loaders, large-scale MCMC sampling, and figure generation scripts) for the associated paper.
